# Chess Engine (C++)

A chess engine written in C++, built as a learning project for the language and for chess engine programming.

## Implemented

- Mailbox 8x8 board representation
- Move generation
- Simple evaluation (material-based)
- Simple search (negamax only)
- FEN parsing

## Next

- Alpha-beta pruning
- UCI support
- PSTs (piece-square tables) for evaluation
